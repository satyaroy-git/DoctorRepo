# Live Hundred Plus Clinic - Dr. Prof. Sandeep Kumar Panigrahi

Professional website for Dr. Prof. Sandeep Kumar Panigrahi, Medicine Specialist (MD) at Live Hundred Plus Clinic, Bhubaneswar.

## How to Add the Doctor's Photo

The website is configured to display the doctor's photo. You need to add the image file:

### Steps:
1. Go to [Google Maps - Live Hundred Plus Clinic](https://www.google.com/maps/place/Dr.+Prof.+Sandeep+Kumar+Panigrahi)
2. Click on the doctor's profile photo
3. Right-click and **Save Image As** → name it `doctor-photo.jpg`
4. Place the file in the root folder of this repository (same folder as `index.html`)
5. Commit and push

The photo will automatically appear in:
- The hero card (circular avatar)
- The About section (larger profile photo)

### Alternative: Use any professional photo
You can also use any professional photo of the doctor. Just name it `doctor-photo.jpg` and place it in the root folder.

## Files
- `index.html` - Main website page
- `styles.css` - All styling
- `script.js` - Interactivity (menu, scroll, form, animations)
- `doctor-photo.jpg` - Doctor's photo (you need to add this)

## Deployment
This is a static website. Deploy on:
- GitHub Pages (Settings → Pages → Deploy from main)
- Netlify (drag & drop)
- Vercel
- Any static hosting
